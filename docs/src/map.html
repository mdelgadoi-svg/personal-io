Personal IO: how everything connects

Live version v2.5 · November 24, 2026 · everything runs in your browser: JavaScript, HTML and CSS (no server)
Plain rules, our own code (no AI, free) Uses Claude AI (your key, small cost) Outside code we copied in (credited) Where your data lives

1. Procrastination

#play · js/play.js + js/games.js
Chess rules: chess.js 1.4.0 by Jeff Hlywa, open source (BSD), JavaScript. js/vendor/chess.js
Piece drawings: Wikimedia Commons (CC BY-SA)
Computer player: ours. Looks a few moves ahead (classic search, not AI). Easy / even / strong. Runs in the background so the screen never freezes. botMove, bot-worker.js
Clock, captured pieces, time of day: ours (v2.5)
Sudoku: ours. Builds a grid with one solution. Full 9x9 or quick 6x6. sudokuNew
Follower box top left: time played, what is next

2. Today's Planning

#today, #plan · js/app.js
Today: green band with the next task, the day's list (check, goal oval), the day's calendar, the add line
Morning proposal: picks your day from stars and deadlines. proposeDay
Plan my day: the day with times; Today / Tomorrow / Later finds the first free time. findFreeSlot
Start screen: 1-minute first steps
Pause + breaks with an end (written answers)
Calm return after 2+ days away: one small thing

3. Life Planning

#goals · js/app.js
Goals: up to 10, in your order, each with a "why". Their order ranks every task, and gives the number in the "goal: #" oval.
Not built yet: the 90-day plan with your triangle (strengths, what you love, context), the scorecard. Phase C of PLAN.md.

The "brains"

who decides things (see the agents picture)
The Follower (agent): watches your day and your play; sets game difficulty, the Follower box, kind lines. rules.js + followTick
Goal picker: Claude reads task names and picks the goal (or "?"). ai.js pickGoals
Other Claude helpers (only with key): first steps, notes, email
Rule helpers: proposal, calm return, Pause answers, break watcher, automatic start

4. Calendar

#calendar · js/app.js + js/google.js
Week view: your Google Calendar events plus your planned tasks
One star on a meeting makes it matter (it joins your day)
Writes back: planned tasks with reminders 10 min before and at the start; the end of a break (your phone rings)

Where your data lives

js/store.js · JSON
This browser first (localStorage): tasks, goals, days, notes, and "moments" (starts, breaks, play, nudges)
Real copy: Google Drive, file personal-io-data.json, folder "Personal IO"
Sync: phone and computer joined item by item; never older data over newer
Only on this device: Claude key, the game in progress, start picture

Connections

nothing else is allowed
Google bridge: a small Google Apps Script (Google's JavaScript) in your Berkeley account, with a secret key. Reads and writes Drive and Calendar. bridge/Code.gs
Claude API: your own key, from the browser. Optional: everything works without it.
Gmail: read-only, only when you tap "Read my last 2 weeks"
Offline: sw.js keeps a copy so the app opens without internet

Builder tools

help build the app; you never see them in it
personal-io-reviewer: a Claude Code agent that tests every change in a real browser before it ships. .claude/agents/
Impeccable: open-source design skill (Apache 2.0) for the look. .claude/skills/
Tests: 70 logic tests (JavaScript) + 18 browser tests (Python, Playwright). Python is only here, never in the app.

How the parts feed each other

Google Calendar→Today, Plan my day, Calendar→the Follower knows what starts soon
Tasks + stars + deadlines + goal order→morning proposal / Plan my day→Today's green band→Start 1 minute→a "start" moment is saved
You play chess or Sudoku→"play" moments saved→the Follower→next game's difficulty + Follower box + kind line→Start 1 minute
A task nobody gave a goal→Claude goal picker (your key)→"goal: #" oval→ranking by goal order
Every change→this browser→Google bridge→Drive copy→your other device
