# Transcripts go here

One plain text file per appearance, named `rowNNN_company_founder.txt` (for example `row176_paid_manny-medina.txt`).

Put this header at the top of each file, then the transcript with speaker labels:

```
company: Paid
founder: Manny Medina
excel_row: 176
source_url: https://www.youtube.com/watch?v=ESa1TdS3dI4
show: Sequoia Capital, Training Data
date: 2025-06-10
host: Pat Grady
transcript_source: youtube captions | show website | whisper | manual
---
HOST: First question ...
FOUNDER: Answer ...
```

Files in this folder are not uploaded to GitHub (see `.gitignore`), because podcast transcripts belong to their publishers.
